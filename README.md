# Finance Desk

Курсовой проект «Веб-система контроля и выполнения операций с интеграцией 1С».

В репозитории находятся учебная конфигурация «1С:Предприятие 8.3» и React-приложение Finance Desk. Конфигурация используется для учёта услуг, оплат и задолженности. XML/BSL-выгрузка: [1c/configuration](1c/configuration).

## Справочники

- **Организации**: организации и их реквизиты.
- **Контрагенты**: заказчики и поставщики, их реквизиты и контакты.
- **Договоры**: организация, контрагент, номер, даты и сумма договора.
- **Номенклатура услуг**: услуги, единицы измерения и цены по умолчанию.
- **Сотрудники**: сотрудники, должности и контакты.
- **Банковские счета**: счета организаций и реквизиты банков.
- **Кассы**: кассы организаций и ответственные сотрудники.

## Перечисления

- **Виды денежных средств**: «Касса», «Банковский счет».
- **Виды операций поступления денежных средств**: «От клиента».
- **Виды операций списания денежных средств**: «Поставщику», «Подотчёт», «Выплата зарплаты».
- **Виды расходов авансового отчета**: «Хозяйственные расходы», «Услуги поставщика».
- **Назначения банковских счетов**: «Расчетный», «Депозитный».

## Документы и операции

- **Сделка**: сведения о сделке с клиентом, без проводок.
- **Акт оказанных услуг**: услуги, количество, цена и автоматический расчёт суммы. При проведении отражает выручку и долг клиента. Можно создать на основании сделки.
- **Поступление денежных средств**: оплата клиента в кассу или на банковский счёт. Можно создать на основании акта, в том числе для частичной оплаты.
- **Получение услуг**: расходы и долг перед поставщиком.
- **Списание денежных средств**: оплата поставщику, выдача денег под отчёт или выплата зарплаты.
- **Авансовый отчёт**: расходы сотрудника из выданных ему денег.
- **Возврат подотчётных сумм**: возврат сотрудником неизрасходованных денег.
- **Начисление оплаты труда**: начисление указанной суммы сотруднику.
- **Перевод между банковскими счетами**: переводы между расчётными и депозитными счетами организации.

Задолженность учитывается по организации, контрагенту и договору. Отдельного расчёта долга по каждому акту нет. В проверках заполнения предусмотрен запрет оплаты сверх долга.

Примеры работы:

- Оформить акт на 10 000 рублей и получить 4 000 рублей. Если других операций по договору нет, остаток долга: 6 000 рублей.
- Оформить получение услуг от поставщика и оплатить их документом списания.
- Выдать сотруднику 3 000 рублей, оформить авансовый отчёт на 2 500 рублей и возврат 500 рублей.
- Начислить сотруднику зарплату и выплатить её через списание денег.

## Учёт и отчёты

План счетов и регистр бухгалтерии **«Хозрасчетный»** используются для записи проводок. **«Виды субконто хозрасчетные»** задают детализацию учёта по организациям, контрагентам, договорам, сотрудникам, кассам и банковским счетам.

Отчёты:

- **Взаиморасчеты с контрагентами**: расчёты и задолженность заказчиков и поставщиков.
- **Денежные средства**: поступления, списания и остатки денег.
- **Подотчетные суммы**: выдачи, расходы, возвраты и остатки по сотрудникам.
- **Акт сверки**: расчёты с контрагентом за период.
- **Оборотно-сальдовая ведомость**: остатки и обороты по счетам, выгрузка в CSV.

Есть печатные формы акта оказанных услуг и акта сверки. Итог печатного акта сверки требует исправления для контрагента, который одновременно является заказчиком и поставщиком.

## Другие объекты

- **Финансовые документы**: общий журнал документов.
- **Финансовое рабочее место**: долги клиентов и перед поставщиками, остатки денег и незакрытые подотчётные суммы, команды создания документов.
- **AIFinanceAPI**: HTTP-сервис для проверки доступности и чтения долгов клиентов, оборотов и проводок. Работа сервиса в текущей базе не проверена.

## React-приложение

Код интерфейса находится в [prototypes/finance-desk-react](prototypes/finance-desk-react). Используются React, TypeScript, Vite, React Router, Radix UI и Motion.

Работают обзор финансов, контрагенты, договоры, документы, обсуждения, ОСВ и сохранение PDF. Есть роли руководителя и сотрудника. Пока это прототип на учебных данных: учёт оплаты меняет только локальные данные, подключения к 1С и MCP из интерфейса нет.

Для запуска нужны Node.js 24 и npm. Из корня репозитория в PowerShell:

```powershell
cd prototypes/finance-desk-react
npm.cmd ci
npm.cmd run dev
```

Открыть http://127.0.0.1:4174/. Зависимости устанавливаются при первом запуске или после изменения `package-lock.json`. В других терминалах вместо `npm.cmd` можно использовать `npm`.

Проверить сборку и открыть собранную версию:

```powershell
npm.cmd run build
npm.cmd run preview
```

Перед запуском preview нужно остановить dev-сервер: оба используют порт 4174.
